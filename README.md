CV Tailor Agent
A local AI agent that tailors your CV to a job advertisement.

Upload or paste a job ad and your CV to generate:

An ATS-optimised CV

A tailored cover letter

A keyword match and gap report

Exportable .docx files

The application runs locally with Ollama, so your CV and job application data remain on your machine.

Features
PDF, DOCX, and TXT CV parsing

Local LLM processing with Ollama

Deterministic ATS keyword matching

CV rewriting based on job requirements

Skills, strengths, and gap analysis

Fact-checking to reduce unsupported claims

Automatic revision when factual issues are detected

DOCX export for the tailored CV and cover letter

JSON fit report

Demo mode with ATS scanning when Ollama is unavailable

The ATS score is calculated using deterministic Python logic rather than generated by the LLM. This makes keyword matching reproducible and transparent.

The agent also checks the rewritten CV against the original CV to reduce fabricated experience, tools, responsibilities, or achievements.

Requirements
Python 3.10+

Ollama

An Ollama-compatible model

Approximately 8 GB RAM for an 8B model

Setup
bash
git clone <repository-url>
cd cv-agent

python -m pip install -r requirements.txt

ollama pull llama3.1:8b

python app.py
Open http://localhost:8000 in your browser.

If Ollama is not running, the application can still perform the deterministic ATS scan. LLM-based features require a running Ollama server.

Configuration
The following environment variables are supported:

Variable	Default	Description
OLLAMA_HOST	http://localhost:11434	Ollama server address
OLLAMA_MODEL	llama3.1:8b	Model used for generation
OLLAMA_TIMEOUT	600	Timeout for LLM requests in seconds
PORT	8000	Web application port
Example:

bash
OLLAMA_MODEL=qwen2.5:14b PORT=9000 python app.py

Main Components
app.py — Flask server, progress updates, and file downloads

parse.py — Extracts text from PDF, DOCX, and TXT files

llm.py — Communicates with Ollama

ats.py — Performs deterministic keyword matching and CV checks

prompts.py — Contains prompts used by the agent

pipeline.py — Coordinates the complete processing workflow

export.py — Creates ATS-friendly DOCX files

To modify the agent's behaviour, edit agent/prompts.py.

Usage Tips
Use the complete job advertisement instead of a short summary.

Make sure the CV contains selectable text. Scanned PDFs may not be parsed correctly.

Run the ATS scan before generating a tailored CV.

Review the gap report before applying.

Always proofread the generated CV and cover letter before submission.

Limitations
Results depend on the selected local language model.

Image-based or poorly formatted PDFs may produce incomplete text.

The fact-checking step reduces hallucinations but does not guarantee perfect accuracy.

Generated content should always be reviewed by the applicant.
